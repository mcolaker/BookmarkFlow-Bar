BF BookmarkFlow Bar

Privacy policy

Privacy without fine print.

Effective date: August 2, 2026

BookmarkFlow Bar is a Chrome extension by Maprins Games that shows the user's Chrome Bookmark Bar as a compact, searchable page overlay. It also provides a custom new-tab page with search and bookmark access.

Data the extension accesses

BookmarkFlow Bar requests access to Chrome bookmarks so it can display bookmark titles, URLs, folders, and favicons inside the extension interface. When the user explicitly uses BookmarkFlow's add, drag, reorder, rename, color, merge, or delete controls, the extension performs the requested bookmark operation locally.

When the user opens the add-bookmark form on a regular web page, BookmarkFlow Bar reads that page's title and URL locally to prefill the form. The information is not saved as a bookmark unless the user confirms the action, and it is not sent to Maprins Games.

General display preferences use Chrome storage sync, so Chrome may synchronize those preferences between a user's signed-in browsers when browser sync is enabled. Per-site exclusions and pinned-folder choices use device-local Chrome storage and are not synchronized by BookmarkFlow.

Data collection and sharing

BookmarkFlow Bar does not collect, sell, rent, transfer, or share user data. It does not send bookmark data, browsing data, settings, or analytics to Maprins Games.

Chrome may synchronize general display preferences through the user's own Chrome Sync account. BookmarkFlow does not operate that service and does not receive data from it.

Limited Use compliance

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Search behavior

The custom new-tab page includes a search box. After the user submits a search query, the browser navigates to Google Search with that query. BookmarkFlow does not receive or store the query.

The bookmark search palette can hide suggestions while its field is empty. Streamer mode can reduce visible bookmark text during screen sharing. These display preferences are handled locally.

Permissions

  • bookmarks: reads the user's Bookmark Bar and bookmark folders, and performs bookmark changes only after explicit user actions.
  • storage: saves general display preferences and device-local per-site/folder choices.
  • favicon: displays Chrome-managed favicons for bookmark URLs.
  • <all_urls>: displays the optional BookmarkFlow interface on regular websites. Chrome-protected pages remain inaccessible.

Optional sign-in and payment page hiding

BookmarkFlow can optionally hide on login, banking, payment, checkout, and wallet-related hosts when the user enables this setting. Users can also manually hide or show the bar per site.

Contact

For a privacy or security report that may contain sensitive details, use GitHub Private Vulnerability Reporting. For general product support, open a GitHub issue without including personal bookmarks, browsing information, or credentials.

Changes

This policy may be updated when extension behavior changes. The effective date above will be updated when material changes are made.

BF BookmarkFlow Bar

Privacy policy

Privacy without fine print.

Effective date: August 5, 2026

BookmarkFlow Bar is a Chrome extension by Maprins Games that shows the user's Chrome Bookmark Bar as a compact, searchable page overlay. It also provides a custom new-tab page with search and bookmark access.

Data the extension accesses

BookmarkFlow Bar requests access to Chrome bookmarks so it can display bookmark titles, URLs, folders, and favicons inside the extension interface. When the user explicitly uses BookmarkFlow's add, drag, reorder, rename, color, merge, or delete controls, the extension performs the requested bookmark operation locally.

On first use after installation or this privacy update, BookmarkFlow keeps bookmark, page-context, preference, and search features off. The setup page presents the data types and purposes described in this policy and enables those features only after the user selects I agree — enable bookmark and page access. Choosing Not now leaves data access disabled.

On regular web pages, BookmarkFlow Bar processes the current page URL, hostname, path, and title locally for current-page bookmark matching, per-site visibility, optional sensitive-site hiding, admin-page docking, and to prefill the add-bookmark form when the user opens it. The content script also performs a bounded local inspection of element geometry, computed positioning styles, and selected body classes so the expanded bar can avoid covering fixed top navigation. This page information is not sent to Maprins Games and is not saved as a bookmark unless the user confirms the add action.

General display preferences use Chrome storage sync, so Chrome may synchronize those preferences between a user's signed-in browsers when browser sync is enabled. Per-site exclusions, pinned-folder choices, and per-folder colors use device-local Chrome storage and are not synchronized by BookmarkFlow because Chrome bookmark IDs are profile-specific.

Data collection and sharing

Maprins Games does not collect, receive, sell, rent, or share extension user data. BookmarkFlow Bar handles the bookmark, page, preference, and search data described above only to provide its user-facing features, and it does not send bookmark data, browsing data, settings, or analytics to Maprins Games.

Chrome may synchronize general display preferences through the user's own Chrome Sync account. BookmarkFlow does not operate that service and does not receive data from it.

BookmarkFlow does not persist click counts, mouse position, keystrokes, or scroll position.

Limited Use compliance

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

User data is used only to provide BookmarkFlow Bar's disclosed bookmark workspace and search features. It is not sold or transferred outside approved use cases, used or transferred for unrelated purposes, used for personalized advertising or profiling, or used to determine creditworthiness or for lending. Maprins Games personnel do not receive or read users' bookmark, page, preference, or search data.

Search behavior

The custom new-tab page includes a search box that uses Chrome's Search API. After the user submits a query, Chrome sends it to the default search provider already selected by the user. BookmarkFlow does not choose or replace that provider and does not receive or store the query.

The bookmark search palette can hide suggestions while its field is empty. Streamer mode can reduce visible bookmark text during screen sharing. These display preferences are handled locally.

Permissions

  • bookmarks: reads the user's Bookmark Bar and bookmark folders, and performs bookmark changes only after explicit user actions.
  • storage: saves general display preferences and device-local per-site, pinned-folder, and folder-color choices.
  • favicon: displays Chrome-managed favicons for bookmark URLs.
  • search: sends user-submitted new-tab searches to the default search provider already selected in Chrome.
  • <all_urls>: displays the optional BookmarkFlow interface on regular websites and locally evaluates the limited page context needed for current-page matching, visibility rules, and non-overlapping placement. Chrome-protected pages remain inaccessible.

Optional sign-in and payment page hiding

BookmarkFlow can optionally hide on login, banking, payment, checkout, and wallet-related hosts when the user enables this setting. Users can also manually hide or show the bar per site.

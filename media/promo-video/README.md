# BookmarkFlow Bar promo video

This dev-only workspace renders the public BookmarkFlow Bar launch film. It is
kept separate from the extension runtime and is excluded from Chrome release
archives.

## Safety contract

- Product media comes only from the reviewed repository assets or the optional
  temporary-profile capture script.
- No regular Chrome profile, personal bookmarks, browsing history, remote
  favicon, analytics service, or third-party runtime asset is used.
- Exact interface text, privacy claims, logo treatment, dimensions, captions,
  and output names are deterministic.
- Generated inputs and rendered outputs stay untracked until they are reviewed
  and intentionally published.

## Commands

```powershell
npm ci
npm run validate
npm run capture
npm run dev
npm run render
```

`npm run capture` is optional. It starts Chrome with a disposable English
profile, synthetic bookmarks, and a loopback-only demonstration page, then
writes seven 1920x1080 source captures under the ignored `public/captures/`
directory. It never opens the regular Chrome profile. The default reviewed
render uses the purpose-cropped store assets; to render from the verified
native captures instead, set `PROMO_USE_NATIVE_CAPTURES=1` before `npm run
render`.

`npm run render` writes the master, social cutdowns, poster, captions, checksums,
and a machine-readable manifest to the repository-level `output/promo-video/`
directory. The manifest status is `PREPARED_NOT_UPLOADED` until a maintainer
intentionally publishes an output to a GitHub Release or social platform.

Node.js 20 or newer and a system FFmpeg/FFprobe installation are required. On
Windows, the renderer uses the exact Remotion `4.0.506` compositor with the
system FFmpeg encoder to produce H.264 High Profile, `yuv420p`, BT.709 video and
48 kHz stereo AAC audio.

## Compositions

| Composition | Output | Duration |
| --- | --- | ---: |
| `BookmarkFlowMaster` | 1920x1080 H.264/AAC | 58 seconds |
| `BookmarkFlowX` | 1920x1080 H.264/AAC | 32 seconds |
| `BookmarkFlowTeaser` | 1080x1350 H.264/AAC | 15 seconds |
| `BookmarkFlowPoster` | 1920x1080 PNG | Still |

The full master is suitable for a GitHub Release and LinkedIn native upload.
The shorter cut is intended for X. The portrait-safe teaser is a secondary
social asset rather than a forced crop of the full desktop interface.

The soundtrack is a deterministic ambient bed generated by
`scripts/prepare-assets.mjs`; it is not downloaded or licensed from a third
party. No voice-over is embedded. The English SRT files provide an accessible
caption and narration script. The GitHub README publishes only the reviewed
one-play GIF and poster; MP4 deliverables, intermediate frames, browser
profiles, and generated inputs remain ignored and are excluded from the Chrome
release archive.

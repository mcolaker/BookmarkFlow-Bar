# BookmarkFlow Bar posting guide

Status: `PREPARED_NOT_POSTED`

The files in this delivery kit use reviewed BookmarkFlow Bar media generated
with synthetic bookmarks. They contain no personal Chrome profile, real
bookmark library, browsing history, account data, analytics input, remote
content, or third-party music.

## Recommended sequence

1. Publish the verified GitHub Release and full product film.
2. Publish and pin the GitHub Discussions announcement.
3. Upload the video natively to LinkedIn and X.
4. Ask for focused feedback in one relevant Reddit community.
5. Submit a plain, technical Show HN post.
6. Publish a useful build story on DEV Community and Indie Hackers.
7. Run a separate Product Hunt launch after early feedback is incorporated.

Check each community’s current rules immediately before posting. Ask for
specific feedback, not votes, artificial engagement, or coordinated upvoting.

## Platform notes

- LinkedIn: upload the 58-second video natively, add the English SRT file, and
  use the LinkedIn still as the thumbnail.
- X: upload the 32-second cut with the primary post; place the Chrome Web Store
  link and feedback request in the first reply.
- Reddit: disclose that you are the developer, use the current self-promotion
  flair where required, and begin with one relevant community rather than
  cross-posting broadly.
- Hacker News: submit the GitHub URL, place the technical context in the first
  comment, and never request or coordinate votes.
- Product Hunt: use the prepared thumbnail and carousel; provide a video URL
  only after the film has a real public URL.
- DEV Community and Indie Hackers: publish useful technical lessons rather than
  a link-only advertisement.

## Anti-spam checklist

- Use the approved media for the channel; do not stretch or invent UI.
- Publish natively where the platform supports video.
- Add captions and meaningful alt text.
- Disclose that you are the developer.
- Ask for focused feedback and answer comments.
- Do not copy the same promotional post across many communities on one day.
- Do not ask for votes, coordinate upvotes, or use engagement groups.
- Record a public URL only after the post is actually published.

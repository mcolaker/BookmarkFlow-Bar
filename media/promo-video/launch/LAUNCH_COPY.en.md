## Indie Hackers

Title:

```text
What I learned building a local-first Chrome extension with no runtime dependencies
```

Body:

```text
I wanted a denser bookmark workflow, but I didn’t want to build another account-backed service.

That led me to create BookmarkFlow Bar: a Manifest V3 extension that turns the bookmarks already in Chrome into a multi-row bar, keyboard search palette, pinned folder rail, and focused new-tab workspace.

Three decisions shaped the project:

1. Keep the bookmark library in Chrome.
2. Use vanilla JavaScript with no runtime package dependencies or build step.
3. Explain broad permissions directly instead of hiding them behind vague privacy language.

The extension is now live on the Chrome Web Store, and the source is available under Apache-2.0:

https://github.com/mcolaker/BookmarkFlow-Bar

https://chromewebstore.google.com/detail/bookmarkflow-bar/iaikobkolclhhpcogacjkenijlfaibpf

For other extension makers: how do you explain technically necessary permissions without overwhelming first-time users? I’d also welcome feedback on the onboarding and distribution approach.
```

Opening:

```text
Chrome’s bookmark bar is useful until a growing library turns it into a scrolling strip of folders and truncated titles.

I built BookmarkFlow Bar to explore a different approach: keep the user’s existing Chrome bookmark library, but give it a customizable multi-row bar, keyboard-driven search palette, pinned folder rail, and focused new-tab workspace.

The project also became an exercise in building a transparent Manifest V3 extension:

- vanilla JavaScript with no runtime package dependencies
- no BookmarkFlow account or developer-operated server
- explicit explanations for bookmarks, search, storage, favicon, and host permissions
- English and Turkish interfaces through Chrome’s native localization system
- an Apache-2.0 repository with contribution and security guidance

This article covers the architectural decisions, privacy tradeoffs, and release checks behind the extension.

Source:
https://github.com/mcolaker/BookmarkFlow-Bar

Chrome Web Store:
https://chromewebstore.google.com/detail/bookmarkflow-bar/iaikobkolclhhpcogacjkenijlfaibpf
```
